## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/vireshaijeri5-web/blinkit-ai-customer-support-chatbot.git
```

### 2. Navigate to the project folder

```bash
cd blinkit-ai-customer-support-chatbot
```

### 3. Install dependencies

If your project uses Node.js and has a `package.json` file:

```bash
npm install
```

### 4. Run the project

Use the command configured for your project in `package.json`, for example:

```bash
npm run dev
```

For a plain HTML, CSS, and JavaScript project, open `index.html` in your browser instead.
