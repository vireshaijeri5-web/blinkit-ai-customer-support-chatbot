## 🔄 File Modification Guide

### Safe to Modify
- ✅ `config.json` - Recommended
- ✅ `script.js` - Advanced
- ✅ `styles.css` - Advanced
- ✅ `index.html` - HTML only

### Be Careful
- ⚠️ `admin-script.js` - Affects admin features
- ⚠️ `admin-styles.css` - Affects admin layout
- ⚠️ `admin.html` - Can break features

### Don't Delete
- ❌ Any core file without backup
- ❌ HTML structure without understanding
- ❌ Key CSS selectors
